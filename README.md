# th06nc 自动避弹辅助

给《东方红魔乡：新典》(th06nc.exe) 用的**外部辅助程序**：读游戏内存拿自机 / 子弹 / 敌人 /
道具位置 → 算安全方向 → 模拟按键。

**不注入、不替换 DLL、不改游戏文件、不联网。**

## 下载与使用

1. 到 [Releases](../../releases/latest) 下载 `th06nc-autododge-v*-win64.zip`
2. **解压到可写目录**（例如 `D:\th06nc-autododge`）—— 别放 `C:\Program Files`，
   保存参数与自动适配地址都要往程序目录写文件
3. 启动游戏（Steam AppID **4659620**）
4. 双击 `th06nc-autododge.exe` → 控制台点「连接游戏」→ 手动进入关卡 → 点「开始」

不需要安装 Python，Windows 10/11 64 位即可。包内 [`使用说明.txt`](发布/使用说明.txt) 有图文步骤。

## 它做什么

| 能力 | 说明 |
|---|---|
| 自动避弹 | 九向候选各外推若干帧弹道，取整个时间窗内最小间隙最大的方向 |
| 自动射击 | 进关卡后按住 `Z` 连射（`tap` 只出零星几发） |
| 自动捡道具 | 带时间模型：只在道具快落到自机高度时水平对齐，不为捡道具把输出走丢 |
| 智能道具线 | 满火力且掉落够多时冲上收集线，全屏掉落强制转成追踪 |
| 自动灵击 | 被击中后 8 帧死亡窗口内按 `X` 取消死亡；九向必死时提前炸 |
| 自动进下一关 | 关卡过渡不退出，开场对话按节奏轻点 `Z` 推进 |
| 玩家让位 | 检测到真人按键就停手（一个键都不发），停手若干秒后自动接管 |

参数全在「⚙ 高级设置…」窗口里，滑条**悬停 0.4 秒**出说明，运行中改动即时生效。
逐项含义 → [`项目文档/04-调参/相关-参数速查-TUNING.md`](项目文档/04-调参/相关-参数速查-TUNING.md)。

## 常见问题

- **杀毒软件报毒** —— PyInstaller 打包的程序常被误报（尤其单文件版）。本项目用文件夹版发布，
  误报率更低；仍被拦就把整个目录加白名单。
- **连接失败 / 读不到内存** —— 先确认游戏在运行；本程序要与游戏**同权限**（游戏以管理员
  启动时，本程序也要以管理员启动）。
- **游戏更新后失效** —— 双击 exe 会自动重定位地址（读 exe 特征，约一分钟，日志 `autofix.log`）。
  程序目录里的 `addr_cache.json` 就是更新后的地址表。
- **提示参数超出滑条范围** —— Spinbox 不挡键入，超范围的值仍生效，但部分参数越界不是「更强」
  而是失效，日志会说明原因。
